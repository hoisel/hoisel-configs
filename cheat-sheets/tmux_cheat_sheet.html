Cheat Sheet — Seus atalhos de Tmux

Um guia rápido (com exemplos) para as configurações e atalhos personalizados do seu ~/.tmux.conf que você usa no dia a dia.

prefix panes windows mouse split layout sync fzf
Data: 23/07/2026
Formato: pt-BR
Escopo: ~/.tmux.conf pessoal
Como usar
Seu prefixo é Ctrl+a (não o padrão Ctrl+b). Atalhos marcados como "sem prefixo" funcionam direto, sem apertar o prefixo antes.
Ctrl+a <tecla>   # atalho normal (com prefixo)
Alt+seta         # atalho direto (sem prefixo)
Exemplo:
Ctrl+a c     # nova window
Ctrl+a r     # recarrega o ~/.tmux.conf
Dica rápida
  • Mouse está ligado (mouse on): dá pra clicar, arrastar borda de pane e trocar de window na status bar.
  • escape-time 0 deixa o prefixo e o Alt/Esc mais responsivos (sem delay perceptível).
  • Janelas e panes começam em 1, não em 0 — alinhado com o teclado numérico.

Detalhes por categoria (com dicas)

Aqui você encontra explicações rápidas, quando usar e exemplos típicos por grupo.

Prefix

Prefix

Ctrl+a

Config: set -g prefix C-a / unbind C-b / bind C-a send-prefix

Troca o prefixo padrão do tmux (Ctrl+b) para Ctrl+a — mais perto do "Home" do teclado e não conflita com o Ctrl+b do Vim.

Exemplos:
  • Ctrl+a c → nova window
  • Ctrl+a " → split padrão do tmux
Prefix

Ctrl+a, Ctrl+a

Config: unbind ^A / bind ^A select-pane -t :.+

Apertar o prefixo duas vezes seguidas cicla para o próximo pane da window — jeito rápido de alternar entre panes sem usar as setas.

Exemplos:
  • Ctrl+a Ctrl+a → vai para o próximo pane

Indexação

Indexação

Base-index em 1

Config: set -g base-index 1 / set -g pane-base-index 1

Windows e panes começam a contar do 1, não do 0 — combina com a ordem física das teclas numéricas.

Exemplos:
  • Ctrl+a 1 → vai para a primeira window
Indexação

Renumeração automática

Config: set -g renumber-windows on

Ao fechar uma window no meio da lista, as demais são renumeradas sequencialmente, sem deixar buracos.

Exemplos:
  • Fechar a window 2 de [1,2,3] vira [1,2] automaticamente.

Comportamento

Comportamento

Nome fixo da window

Config: set -g allow-rename off

Impede que o shell (ex.: ao rodar um comando) sobrescreva automaticamente o nome que você deu à window.

Exemplos:
  • Renomear com Ctrl+a , e o nome permanece mesmo rodando outros comandos.
Comportamento

Mouse habilitado

Config: set -g mouse on

Habilita clique para trocar de pane/window, scroll no histórico e redimensionar panes arrastando a borda.

Exemplos:
  • Arrastar a borda entre dois panes para redimensionar.
  • Clicar numa aba da status bar para trocar de window.

Performance & Compatibilidade

Performance

Sem delay do prefixo

Config: set -s escape-time 0

Remove o pequeno atraso padrão do tmux ao interpretar Esc/Alt, deixando prefixo e atalhos mais responsivos.

Exemplos:
  • Importante para quem usa Vim/Neovim dentro do tmux (evita delay ao sair do modo insert).
Performance

Teclas estendidas

Config: set -s extended-keys on / set -as terminal-features 'xterm*:extkeys'

Habilita sequências de teclas estendidas do tmux 3.2+, necessárias para combinações como Ctrl+Alt+Seta chegarem corretamente ao tmux.

Exemplos:
  • Sem isso, Ctrl+Alt+←/→ podem não funcionar em alguns terminais.

Navegação — Janelas

Janelas

Ctrl+Alt+← / Ctrl+Alt+→

Config: bind -n C-M-Left previous-window / bind -n C-M-Right next-window

Navega para a window anterior/próxima sem precisar apertar o prefixo antes.

Exemplos:
  • Ctrl+Alt+→ → próxima window
  • Ctrl+Alt+← → window anterior

Navegação — Panes

Panes

Ctrl+←↑→↓

Config: bind -n C-Left/C-Right/C-Up/C-Down select-pane -L/-R/-U/-D

Move o foco entre panes na direção da seta, sem precisar do prefixo.

Exemplos:
  • Ctrl+→ → pane à direita
  • Ctrl+↑ → pane acima

Split

Split

Alt+← / Alt+→

Config: bind -n M-Left split-window -h / bind -n M-Right split-window -h

Cria um split vertical (panes lado a lado) sem precisar do prefixo.

Exemplos:
  • Alt+→ → novo split vertical
Split

Alt+↑ / Alt+↓

Config: bind -n M-Up split-window -v / bind -n M-Down split-window -v

Cria um split horizontal (panes empilhados) sem precisar do prefixo.

Exemplos:
  • Alt+↓ → novo split horizontal
Split

Ctrl+a ← / Ctrl+a →

Config: bind -r Left split-window -h / bind -r Right split-window -h

Mesmo split vertical, dentro do prefixo. Como usa bind -r, dá pra repetir a tecla algumas vezes sem apertar o prefixo de novo.

Exemplos:
  • Ctrl+a → → split vertical
Split

Ctrl+a ↑ / Ctrl+a ↓

Config: bind -r Up split-window -v / bind -r Down split-window -v

Mesmo split horizontal, dentro do prefixo, com repetição via bind -r.

Exemplos:
  • Ctrl+a ↓ → split horizontal

Layout de Painéis

Layout

Ctrl+a Alt+1 / Ctrl+a Alt+2

Comando: select-layout even-horizontal / select-layout even-vertical

Alt+1 deixa os panes com a mesma largura (lado a lado). Alt+2 deixa com a mesma altura (empilhados).

Exemplos:
  • Ctrl+a Alt+1 → 3 panes lado a lado, mesma largura
  • Ctrl+a Alt+2 → 3 panes empilhados, mesma altura
Layout

Ctrl+a Alt+5

Comando: select-layout tiled

Organiza todos os panes em grade, com largura e altura uniformes entre eles — a opção certa quando você quer todos do mesmo tamanho nas duas direções.

Exemplos:
  • 4 panes → grade 2x2, todos do mesmo tamanho.
Layout

Ctrl+a Espaço

Comando: next-layout

Alterna ciclicamente entre os 5 layouts pré-definidos do tmux, sem precisar lembrar o número de cada um.

Exemplos:
  • Ctrl+a Espaço várias vezes → percorre even-h, even-v, main-h, main-v, tiled.

Janelas — Criar, Fechar & Renomear

Janelas

Ctrl+a c

Comando: new-window

Cria uma nova window (aba) na sessão atual. Bind padrão do tmux — só muda porque seu prefixo é Ctrl+a.

Exemplos:
  • Ctrl+a c → nova window vazia
Janelas

Ctrl+a &

Comando: kill-window

Fecha a window atual, junto com todos os panes dentro dela.

Exemplos:
  • Ctrl+a & → pede confirmação → y fecha
Fecha todos os panes da window de uma vez — confirme antes de aceitar.
Janelas

Ctrl+a ,

Comando: rename-window

Abre um prompt para renomear a window atual. Como allow-rename off está ativo, o nome não é sobrescrito depois pelo shell.

Exemplos:
  • Ctrl+a , → apaga o nome antigo → digita o novo → Enter

Painéis — Fechar & Renomear

Painéis

Ctrl+a x

Comando: kill-pane

Fecha só o pane atual (os outros panes da window continuam abertos).

Exemplos:
  • Ctrl+a x → pede confirmação → y fecha
Painéis

Ctrl+a :

Comando: select-pane -T "nome"

Tmux não tem uma tecla própria para "renomear pane" como tem para window — o jeito é definir um título via command-line.

Exemplos:
  • Ctrl+a : → digite select-pane -T "build" → Enter
O título só aparece na tela se pane-border-status estiver ativado — hoje seu .tmux.conf não define isso (ver nota técnica).

Utilidades

Utilidades

Ctrl+a r

Config: bind r source-file ~/.tmux.conf \; display-message "Config reloaded"

Recarrega o ~/.tmux.conf na sessão atual, sem precisar matar o servidor tmux ou reabrir a sessão.

Exemplos:
  • Edite o .tmux.conf, salve, e dê Ctrl+a r.

Sincronização

Sincronização

Alt+i

Config: bind -n M-i setw synchronize-panes

Liga/desliga o modo sincronizado: tudo que você digita é enviado para todos os panes da window ao mesmo tempo. Sem prefixo.

Exemplos:
  • Rodar o mesmo comando em vários servidores/panes ao mesmo tempo.
Não esqueça de desligar (Alt+i de novo) depois — senão você continua digitando em todos os panes.

Busca

Busca

Ctrl+a s

Config: bind-key s display-popup -E "zsh -lc '...'"

Abre um popup com fzf listando todas as windows (índice + nome); ao escolher uma, pula direto para ela.

Exemplos:
  • Ctrl+a s → digite parte do nome da window → Enter
Requer fzf instalado e zsh disponível no PATH.
Dica: prefira os atalhos "sem prefixo" (Ctrl/Alt+setas) para navegação rápida no dia a dia.

Notas técnicas (o que os binds mais complexos realmente fazem)

Detalhes sobre os pontos menos óbvios da sua config, incluindo o popup com fzf.

Ctrl+a s — popup fzf

Objetivo: escolher e pular para uma window via busca fuzzy, sem precisar decorar índices.

Como funciona (alto nível):
display-popup -E "zsh -lc '
tmux list-windows -F "#{window_index}:#{window_name}"
| fzf --reverse --border --prompt="Window > "
| cut -d: -f1
| xargs -I {} tmux select-window -t {}'"
  • tmux list-windows lista todas as windows como índice:nome.
  • fzf abre um filtro interativo dentro do popup (-E = fecha o popup ao sair).
  • cut -d: -f1 pega só o índice escolhido.
  • xargs ... tmux select-window -t {} troca para a window escolhida.
Dependências
Precisa de fzf instalado e zsh no PATH. Sem eles, o popup abre e fecha sem fazer nada.

Quick pane cycling (Ctrl+a, Ctrl+a)

Objetivo: alternar rapidamente entre panes, técnica clássica documentada no wiki do tmux.

unbind ^A
bind ^A select-pane -t :.+
  • Como o prefixo é C-a, rebindar ^A dentro da tabela de prefixo faz o "duplo Ctrl+a" funcionar.
  • select-pane -t :.+ seleciona o próximo pane na ordem (cíclico).

Alt/Ctrl+Setas e terminais

Objetivo: fazer combinações tipo Ctrl+Alt+Seta e Alt+Seta chegarem corretamente ao tmux.

  • extended-keys on + terminal-features 'xterm*:extkeys' habilitam essas sequências (tmux 3.2+).
  • Terminais modernos (iTerm2, Kitty, WezTerm, Alacritty, Windows Terminal) costumam suportar isso nativamente.
  • O Terminal.app do macOS às vezes precisa configurar "Option as Meta key" para o Alt funcionar como esperado.

Redundância nos splits por Alt+Seta

Observação: Alt+← e Alt+→ fazem exatamente a mesma coisa (split-window -h), e o mesmo vale para Alt+↑/Alt+↓ (split-window -v).

  • Não há diferenciação de lado/posição do novo pane — qualquer seta horizontal cria split vertical, qualquer seta vertical cria split horizontal.
  • Isso é útil se você só quer decorar "seta horizontal = lado a lado, seta vertical = empilhado", sem se preocupar com a direção exata.
Se quiser diferenciar
Dá pra usar split-window -h -b (before) em uma das setas para o novo pane aparecer à esquerda em vez de à direita, por exemplo.

Renomear pane (select-pane -T)

Objetivo: dar um "nome" a um pane, algo que o tmux não tem como tecla única por padrão (só windows têm rename-window).

Ctrl+a :
select-pane -T "nome"
  • select-pane -T define um título interno para o pane atual.
  • Esse título só fica visível na tela se você ligar pane-border-status (ex.: set -g pane-border-status top) — configuração que não está no seu .tmux.conf hoje.
Sem pane-border-status ativo
O comando roda sem erro, mas você não vai ver o título em lugar nenhum. Se quiser realmente visualizar/usar isso no dia a dia, adicione set -g pane-border-status top (ou bottom) ao .tmux.conf.

Layouts pré-definidos do tmux

Objetivo: reorganizar o tamanho dos panes sem precisar redimensionar um por um.

  • even-horizontal (Alt+1): panes lado a lado, mesma largura, altura total.
  • even-vertical (Alt+2): panes empilhados, mesma altura, largura total.
  • main-horizontal (Alt+3) / main-vertical (Alt+4): um pane "principal" maior + os demais menores.
  • tiled (Alt+5): grade uniforme — largura e altura iguais para todos.
Todos esses binds já vêm por padrão no tmux (dentro do prefixo); não foram customizados no seu .tmux.conf.
Checklist rápido
  • Prefixo é Ctrl+a, não Ctrl+b.
  • fzf e zsh precisam estar instalados para o Ctrl+a s funcionar.
  • Depois de editar o .tmux.conf, use Ctrl+a r para recarregar.
  • Lembre de desligar o Alt+i (sync-panes) depois de usar.
  • Ctrl+a x e Ctrl+a & pedem confirmação — não fecham nada sem avisar.
  • Para ver o "nome" de um pane, ative pane-border-status no .tmux.conf.
Fim da cheat sheet — personalize à vontade e mantenha seu ~/.tmux.conf documentado.
